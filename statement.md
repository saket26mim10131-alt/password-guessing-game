# Project Statement

## Problem Statement

The Password Guessing Game is a simple Python-based game where the user tries to guess a predefined password within a limited number of attempts. The program provides hints after incorrect guesses to help the user make a better guess.

## Scope

The project focuses on implementing a simple password guessing game using basic Python programming concepts.

## Target Users

This project is intended for beginners who want to understand basic Python programming concepts through a simple interactive game.

## High-Level Features

- Limited number of attempts
- Password validation
- Hints for incorrect guesses
- Four-digit number checking
- Attempts-left display
- Success and game-over messages
