# Password Guessing Game

## About the Project

Password Guessing Game is a simple Python program in which the user has to guess a predefined password with the help of hints within a limited number of attempts.

The idea is similar to entering a password on a mobile phone. If the entered password is incorrect, the program provides hints to help the user make another guess.

## Features

- Maximum of 5 attempts
- Hints for incorrect guesses
- Checks whether the entered number is a 4-digit number
- Displays the number of attempts left
- Displays a success message when the password is guessed correctly
- Displays a game-over message when all attempts are used

## How to Run

### Requirements

Enter your password guess when prompted.
How the Game Works
The user enters a password guess.
The program checks the entered guess.
If the guess is incorrect, the program provides a relevant hint.
The program displays the number of attempts left.
The game ends when the user guesses the password correctly or all 5 attempts are exhausted.
Example

Suppose the password is set to a particular number. When the user enters an incorrect number, the program provides a hint such as asking the user to try a higher or lower number. The user can use these hints to make another guess.
